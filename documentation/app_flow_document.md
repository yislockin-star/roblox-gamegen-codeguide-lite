# AI-Powered Roblox Game & Asset Generator App Flow

## Onboarding and Sign-In/Sign-Up
A new developer first arrives at the platform via a public landing page that briefly explains how they can use natural language prompts to generate Roblox game scripts and assets. On this page, a clear call to action invites them to sign up or log in. When the user clicks Sign Up, they are taken to a Clerk-powered registration form. They can choose to register with an email address and password or use a social login option if it is enabled in the Clerk dashboard. After entering their credentials, they receive a verification email. Once they verify, they are automatically signed in and redirected to the main dashboard. Returning users click Log In and enter their email or social login credentials on the Clerk-hosted sign-in page. If a user forgets their password, they select the “Forgot Password” link, submit their email address, and receive a password reset link to establish a new password. A Sign Out button is always available in the header for the user to securely end their session.

## Main Dashboard or Home Page
Immediately after signing in, the developer lands on the main dashboard. The top of the page features a branded header with the application name, a toggle for light and dark mode, and the user avatar with a dropdown for quick access to Settings and Signing Out. Along the left side there is a vertical navigation menu that shows links for Projects, Generate New Asset, Credits, and Settings. The central area is dominated by the Prompt Interface, where the developer can type in natural language requests for game mechanics or assets. Above the input field, the dashboard displays the developer’s remaining credit balance so they know how many generations they can still perform. Below the input area is a live feed of recent asset generations, showing a thumbnail or snippet of the Lua code along with a timestamp. A button at the top right of the dashboard labelled “New Project” allows the developer to create a project container for organizing upcoming asset generations.

## Detailed Feature Flows and Page Transitions
When a developer wants to generate a new game asset, they click the “Generate New Asset” link in the sidebar or use the prompt input right on the dashboard. They type a request such as “Create a spinning gold coin that gives 10 points on touch” and press Enter. The interface transitions to a streaming view that shows the Lua code being generated in real time. Behind the scenes, the app sends the prompt to the `/api/chat` endpoint, where the system prompt is prepended, and the Vercel AI SDK streams back the completed script. Once the generation finishes, the system automatically saves the new asset to Supabase, associating it with the developer’s current project. The user is returned to the project detail page where they see a list of all generated assets within that project. Clicking on an asset opens a detailed view that displays the full Lua script in a code block with syntax highlighting and a Copy to Clipboard button. From this view, developers can rename the asset, delete it, or create a variation using an “Edit Prompt” button. If the developer runs low on credits, they are prompted with a modal explaining that they need to top up their balance before proceeding.

Developers can also click Projects in the sidebar to see a gallery of all their projects. Each project tile shows a name, creation date, and asset count. Clicking a tile brings them to that project’s detail page. In addition, there is a Credits page that lists available credit packages. Selecting a package takes the developer to a Stripe-hosted checkout, and upon successful payment the platform receives a webhook that updates the developer’s credit balance in Supabase. After a credit purchase, the developer is redirected back to the Credits page with an updated balance displayed.

## Settings and Account Management
The Settings area is accessible from the header dropdown or the sidebar. On the Account tab, developers can update their display name, change their email, link or unlink social accounts, or reset their password. A Preferences tab allows them to toggle dark mode, adjust the default code font size, and enable or disable streaming animation in the generator interface. Under the Billing section, developers can view their current subscription plan, see upcoming invoices, and manage payment methods. All changes are saved immediately via server-side handlers, and a confirmation banner appears at the top of the page whenever an update succeeds. After adjusting settings, developers click a “Return to Dashboard” link in the sidebar to resume prompting and project work.

## Error States and Alternate Paths
If a developer submits a prompt without sufficient credits, a modal appears explaining they have depleted their balance, offering a link to purchase more credits or to view existing usage. Network failures during generation trigger an inline error message in the streaming view, allowing the user to retry or cancel. Invalid prompt inputs—such as an empty submission—cause the prompt field border to turn red and display a short error description above the field. Attempts to access projects or assets without proper authentication are intercepted by Clerk’s middleware, redirecting the user to the sign-in page. If Supabase rejects a write or read request due to Row Level Security, the user sees a generic permission error with a link to contact support. Each error screen provides a clear call to action so the user can correct the issue and resume their workflow.

## Conclusion and Overall App Journey
A developer begins by discovering the platform’s landing page, signs up through Clerk, and verifies their email. They arrive at the dashboard where they see their credit balance and project list. By typing natural language prompts, they generate Lua code in real time, which is saved under projects for easy retrieval. Throughout their journey, they can view and manage past assets, purchase additional credits via Stripe, and customize account details in Settings. Error messages guide them through missing credits, authentication issues, or connectivity problems. Signing out or returning to the dashboard is always just one click away. This flow ensures that from the moment a developer registers to the moment they paste generated code into Roblox Studio, every step is intuitive, connected, and secure.
